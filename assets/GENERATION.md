# 七只青蛙的图像素材

工具：内置 imagegen，使用用户提供的三只树蛙照片作参考，透明背景。

文件：frogs-atlas.png。7 列 × 2 行，共 14 帧。第一行闭嘴，第二行张嘴；列顺序依次对应呱队长、小豆、阿低、泡泡、咕咕、歪歪、大福。页面按单元格分别绘制，每只青蛙可独立切换嘴形。

最终提示词：

Edit the reference photograph into a production game sprite atlas. Exactly fourteen isolated photorealistic tree frog cutouts on transparent background arranged in a precise 7 column by 2 row equal-cell grid. The seven columns are seven individual frogs from left to right. TOP ROW: all seven frogs mouth closed. BOTTOM ROW: the exact same seven frogs in identical pose, scale, position and lighting, but each with a clearly wide open singing mouth. Match reference blue-green textured skin, huge glossy eyes, orange underbellies and orange toes; individual subtle variations of build and head tilt distinguish the seven. All frontal, full bodies, crouching/gripping pose, no branch, no background, no text, no labels, no accessories. Each frog centered in its own equal cell with generous transparent padding, no overlap. Wide landscape atlas. Every top-bottom pair must align perfectly for animation. This single sprite atlas will be used to independently animate seven voices.
