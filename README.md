# 呱唧 GUAJI

七只青蛙在池塘里组建了一支阿卡贝拉乐队。你是它们的指挥家：不必完美，呱得开心。

首版可玩原型，包含微信小游戏入口和共享代码的手机网页试玩版，无 npm 依赖。

## 开始试玩

安装 Node.js 18 或更高版本，在工程目录运行：

```sh
npm start
```

浏览器打开 http://localhost:4173 。电脑和手机处于同一局域网时，可通过电脑局域网 IP 的 4173 端口访问，需系统防火墙允许。也可以直接打开 index.html 在桌面浏览器试玩。

## 微信开发者工具

1. 导入本文件夹，项目类型选择 **小游戏**，而非普通 WXML 小程序。
2. 将 project.config.json 中的 touristappid 替换为自己的微信小游戏 AppID；游客模式的支持情况取决于开发者工具。
3. 入口是 game.js，使用 wx.createCanvas、触摸事件与 wx.createWebAudioContext。
4. 在真机上检查首触发声、滑奏延迟、息屏/切后台停止、耳机与外放、刘海屏安全区及音频素材解码，然后上传体验版。

当前尚未在微信开发者工具和 iOS/Android 真机验收，未上传、审核或发布。网页试玩不等于微信发布。API 参考：[微信官方小游戏类型定义](https://github.com/wechat-miniprogram/minigame-api-typings)、[WebAudioContext](https://developers.weixin.qq.com/minigame/dev/api/media/audio/wx.createWebAudioContext.html)。

## 怎么玩

- 长按 1–7：do、re、mi、fa、sol、la、si；松手停止，持续时间就是延音时间。
- 左右滑动切换音符，手指上下移动相对于按下位置弯音，范围 ±180 音分；来回滑动产生手动颤音。
- 下方选择 11 个八度：C−2 到 C+8。以 C4 为中央 C，A4=440 Hz。这是自定义宽音域，不代表钢琴通常有 11 个完整八度。极端音区可能不可闻或发生混叠，建议 C2–C6。
- “录制”保存最长 30 秒的音符、时长、八度与弯音轨迹；再次点击停止。“回放”播放刚才的演奏。录音是内存中的演奏事件，不是导出的音频文件，刷新会清除。
- “跟唱”进入《小星星》练习，两秒准备后，音块经过金色竖线时长按对应音。按匹配时长计分，必须使用 C4，且弯音偏移在 70 音分以内。
- “原声”读取本地音频，微信端从聊天文件选择。素材不上传服务器。支持当前平台可解码的格式，建议短 WAV，长度 0.03–10 秒、文件小于 10 MB。

## 声音设计及原型边界

默认是七种谐波配方生成的合成占位蛙音，并非真人阿卡贝拉录音。导入素材应提前裁为稳定、干净的单音，**基准为 C4**；首版不做自动基频识别、AI 声线转换或保留共振峰的变调。通过 playbackRate 变调并循环延音，高低音会同时改变语速与音色，素材首尾不连续可能出现循环接缝。

七只青蛙分别响应七个音级；首版是单指单声部演奏，音轨显示按成员分行的演奏记录。尚未实现多声部叠录、完整歌曲库、故事关卡、进度持久化、分享导出和商业化。

后续建议：每只青蛙准备独立元音素材与采样基准音、制作无缝 sustain 循环和 release 尾音，再增加多轨循环录音与关卡编排。

## 工程

- app.js：共用画面、触控、录制回放、挑战。
- audio.js：合成缓冲、素材解码、变调和淡出。
- core.js：十二平均律、琴键命中、挑战判定。
- game.js / game.json / project.config.json：微信小游戏入口及配置。
- index.html：浏览器入口。
- tools/serve.cjs：本地静态服务器。

运行 `npm test` 验证核心逻辑及声音生命周期。画面全部由 Canvas 绘制，不需要下载外部美术资源。
